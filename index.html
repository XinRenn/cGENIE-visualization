How cGENIE computes, step by step

The main program is one do koverall = 1, N loop. On every master step (about 18 hours) it goes through the modules in a fixed order and asks whether each one is due: the fast atmosphere runs every step, the ocean every 5, ocean biogeochemistry every 10, and the sediments once a year. Modules never call each other; they exchange fluxes and states through shared interface arrays.

Numbers are for cookie’s default 36×36×16 grid (worjh2 topography, CBSR = climate + BIOGEM + SEDGEM + ROKGEM base config), with time steps written automatically by runcookie.sh.
